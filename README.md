# BeautySalon — Салон красоты

---

Лабораторная работа №1 по дисциплине «Разработка корпоративных приложений».

---

## Описание задания

Реализация объектной модели данных для предметной области «Салон красоты» и unit-тестов на основе LINQ-запросов.

**Вариант:** 13
**База данных:** MS SQL Server
**Брокер сообщений:** RabbitMQ

---

## Используемые технологии

- **.NET 10** — платформа разработки
- **ASP.NET Core Web API** — серверная часть
- **.NET Aspire 13.5** — оркестрация проектов
- **xUnit v3** — unit-тестирование
- **Bogus** — генерация тестовых данных
- **Entity Framework Core** — ORM

---

## Архитектура решения

Решение построено по принципам чистой архитектуры (Clean Architecture):

| Проект | Назначение |
|--------|-----------|
| `BeautySalon.Domain` | Сущности предметной области, перечисления, датасид |
| `BeautySalon.Infrastructure` | Работа с БД (EF Core, DbContext) |
| `BeautySalon.Server` | Web API сервер |
| `BeautySalon.DataGenerator` | Сервис генерации данных (Bogus) |
| `BeautySalon.Tests` | Unit-тесты (xUnit v3) |
| `BeautySalon.AppHost` | Оркестратор Aspire |
| `BeautySalon.ServiceDefaults` | Общие настройки Aspire |

### Диаграмма предметной области

- **Person** (абстрактный) — базовый класс для `Client` и `Master`
- **Client** — ФИО, пол, дата рождения, телефон
- **Master** — ФИО, пол, паспорт, специализация, стаж
- **Service** — название, категория, стоимость, длительность
- **Appointment** — дата/время, клиент, мастер, услуга, признак постоянного клиента

##  Как запустить

### Предварительные требования
- .NET 10 SDK
- Aspire Workload (`dotnet workload install aspire`)

### Запуск через Aspire
```bash
dotnet run --project BeautySalon.AppHost
```
Откроется Aspire Dashboard, где можно увидеть все запущенные сервисы.

---

### Запуск тестов
```bash
dotnet test BeautySalon.Tests
```

---

## Реализованные unit-тесты
1. Вывод мастеров со стажем не менее 5 лет

2. Вывод «окошек» выбранного мастера (промежутки между записями)

3. Топ-5 наиболее популярных услуг

4. Количество повторных записей клиентов за последний месяц

5. Клиенты, записанные к нескольким мастерам (сортировка по дате рождения)
